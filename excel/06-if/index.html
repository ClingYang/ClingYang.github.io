第06章：IF 函数 —— 让公式会"判断"

条件判断：嵌套IF成绩评级、AND/OR多条件组合

2026-07-28
阅读时长: 3 分钟

📥 本章配套练习册（数据已录入、写完公式自动判分）：点击下载 第06章-IF函数-练习.xlsx

难度：⭐⭐ | 建议用时：40 分钟 | 前置知识：前几章的基础函数

本章学习目标

  • 会用 IF 做"如果……就……否则……“的二选一判断
  • 掌握 6 个比较运算符
  • 会用嵌套 IF 做多等级判断（如成绩评级）
  • 了解 AND / OR 辅助函数

一、这个函数是干什么的？

IF 的英文意思是"如果”。它让公式具备判断能力，是 Excel 最重要的函数之一。

生活化理解：

  • 如果成绩 ≥ 60，就显示"及格"，否则显示"不及格"
  • 如果库存 < 10，就提醒"补货"，否则显示"正常"

这正是 IF 的语法结构。

二、语法结构 

1

=IF(判断条件, 条件成立时返回什么, 条件不成立时返回什么)
参数 是否必须 说明
判断条件 必须 一个能得"真/假"结果的比较，如 B2>=60
成立时返回 必须 条件为真时显示的内容
不成立时返回 可选 条件为假时显示的内容（省略则显示 FALSE）

比较运算符（写条件的工具）

运算符 含义 例子
= 等于 B2=60
> 大于 B2>60
< 小于 B2<60
>= 大于等于 B2>=60
<= 小于等于 B2<=60
<> 不等于 B2<>60

两条铁律

  1. 文本结果必须加英文双引号："及格" 对，及格 错（报 #NAME?）
  2. 数字结果不加引号：返回 5000 就写 5000

三、基础示例（手把手）

示例1：判断及格与否

成绩表，B2 是张三的成绩 85，在 C2 输入：

1

=IF(B2>=60, "及格", "不及格")

结果：及格

逐步解读：

  1. 先看条件 B2>=60：85 ≥ 60 → 成立（真）
  2. 条件成立 → 返回第二个参数 "及格"
  3. 如果 B2 是 58，条件不成立 → 返回第三个参数 "不及格"

把 C2 的公式往下拖动复制，整列自动判断——这就是相对引用自动变化的功劳。

示例2：判断是否满分 

1

=IF(B2=100, "满分", "")

结果：B2 不是 100 时显示空白。

技巧：""（两个紧挨的英文双引号）表示"空文本"，让不成立时什么都不显示，表格更干净。

示例3：IF 里放计算式

业绩提成：业绩 ≥ 10000 按 5% 提成，否则没有提成：

1

=IF(B2>=10000, B2*0.05, 0)

解读：IF 的第二、三参数不只是固定内容，可以是任何算式。

四、进阶用法

1. 嵌套 IF：多等级判断（重点！）

成绩评级：≥90 优秀，≥80 良好，≥60 及格，其余不及格：

1

=IF(B2>=90, "优秀", IF(B2>=80, "良好", IF(B2>=60, "及格", "不及格")))

理解方法——像过安检一样一层一层往下筛：

1
2
3
4
5
6
7

B2≥90？ ──是──→ 优秀（结束）
   │否
B2≥80？ ──是──→ 良好（结束）
   │否
B2≥60？ ──是──→ 及格（结束）
   │否
   └──→ 不及格（结束）

关键：判断必须从高到低排。因为一旦走到第二层，就已经说明"不满足 90"了，所以第二层只需写 >=80（此时隐含含义是 80~89）。

⚠️ 括号配对：嵌套几层 IF，结尾就有几个 )。Excel 会用不同颜色帮你配对，写错了会提示。

2. AND / OR：同时判断多个条件

函数 含义 例子
AND(条件1,条件2,...) 所有条件都成立才是真 AND(B2>=60, C2>=0.9)
OR(条件1,条件2,...) 任意一个成立就是真 OR(B2>=90, C2>=0.95)

成绩和出勤率都达标才算通过：

1

=IF(AND(B2>=60, C2>=0.9), "通过", "不通过")

五、常见错误与注意事项

问题 原因 解决
#NAME? 文本没加引号：IF(B2>=60,及格,不及格) 文本加英文双引号
判断全部显示同一结果 比较的是文本型数字（如"85"） 把数据列转为数值格式
嵌套时结果错乱 判断顺序写反（先写 >=60 再写 >=90） 必须从大到小筛
公式括号报错 嵌套 IF 括号没配平 数清楚每个 IF 都要有自己的右括号
60<=B2<=80 写法无效 Excel 不支持连写区间 用 AND(B2>=60, B2<=80)

六、练习题（请先独立完成）

练习数据准备

A B C
1 姓名 成绩 出勤率
2 张三 85 95%
3 李四 58 92%
4 王五 72 85%
5 赵六 91 98%
6 孙七 60 88%

题目

题号 题目 在何处作答
1 判断每人是否及格（≥60 显示"及格"，否则"不及格"） D2，向下填充
2 成绩 ≥90 显示"表扬"，否则显示空白 E2，向下填充
3 成绩评级：≥90"优秀"、≥80"良好"、≥60"及格"、其余"不及格"（嵌套IF） F2，向下填充
4 成绩≥60 且 出勤率≥90% 显示"通过"，否则"不通过" G2，向下填充
5 成绩≥90 或 出勤率≥95% 显示"表现突出"，否则空白 H2，向下填充

附加题（奖金计算，新数据）：

A B
1 员工 业绩
2 小A 120000
3 小B 86000
4 小C 45000
题号 题目
6 业绩 ≥100000 发 5000 奖金，≥50000 发 2000，否则 0（在 C2 写公式并向下填充）

七、练习讲解（做完再看）

第1题讲解

最基础的二选一：=IF(B2>=60,"及格","不及格")，向下拖动填充。孙七正好 60 分，>= 包含等于，所以是"及格"。

第2题讲解

不成立时显示空白用 ""：=IF(B2>=90,"表扬","")。只有赵六 91 分显示"表扬"。

第3题讲解

从高到低三层嵌套：

1

=IF(B2>=90,"优秀",IF(B2>=80,"良好",IF(B2>=60,"及格","不及格")))

验证张三 85：第一层 85≥90？否 → 第二层 85≥80？是 → “良好” ✓ 验证孙七 60：第一层否 → 第二层否（60<80）→ 第三层 60≥60？是 → “及格” ✓ 再次强调顺序：如果把 >=60 放第一层，85 分的人会在第一层就被判成"及格"，永远到不了"良好"。

第4题讲解

两个条件同时满足用 AND：=IF(AND(B2>=60,C2>=0.9),"通过","不通过")。

  • 张三：85≥60 ✓ 且 95%≥90% ✓ → 通过
  • 王五：成绩 ✓ 但出勤 85% ✗ → 不通过
  • 孙七：成绩 ✓ 但出勤 88% ✗ → 不通过

注意出勤率 90% 写成 0.9 或 90% 都可以。

第5题讲解

任一满足用 OR：=IF(OR(B2>=90,C2>=0.95),"表现突出","")。

  • 张三：成绩 85 ✗，但出勤 95%≥95% ✓ → 表现突出
  • 赵六：91≥90 ✓ → 表现突出（两个都满足也算）

第6题讲解

奖金是"数值结果"，不要加引号：

1

=IF(B2>=100000,5000,IF(B2>=50000,2000,0))

小A 120000 → 第一层命中 5000；小B 86000 → 第二层命中 2000；小C 45000 → 都不满足 0。

八、参考答案

题号 公式 张三 李四 王五 赵六 孙七
1 =IF(B2>=60,"及格","不及格") 及格 不及格 及格 及格 及格
2 =IF(B2>=90,"表扬","") （空） （空） （空） 表扬 （空）
3 =IF(B2>=90,"优秀",IF(B2>=80,"良好",IF(B2>=60,"及格","不及格"))) 良好 不及格 及格 优秀 及格
4 =IF(AND(B2>=60,C2>=0.9),"通过","不通过") 通过 不通过 不通过 通过 不通过
5 =IF(OR(B2>=90,C2>=0.95),"表现突出","") 表现突出 （空） （空） 表现突出 （空）

第6题：=IF(B2>=100000,5000,IF(B2>=50000,2000,0)) → 小A 5000、小B 2000、小C 0

本章小结

  • =IF(条件, 成立结果, 不成立结果)，文本结果必须加英文双引号，"" 表示空白
  • 多等级判断用嵌套 IF，等级从高到低依次筛
  • 多条件：全部满足用 AND，任一满足用 OR
  • 区间判断不能连写 60<=B2<=80，要用 AND(B2>=60,B2<=80)
