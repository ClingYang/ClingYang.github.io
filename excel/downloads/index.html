17个自动判分Excel练习册：数据已录入，写完公式自动判对错

2026-07-28
阅读时长: 1 分钟

与教程各章配套的 .xlsx 练习册：数据已录入、题目已列好、写完公式自动判分（✓变绿 / ✗变红）。 点击即可下载，用 Excel 或 WPS 打开。

使用说明

  1. 下载后用 Excel（或 WPS）打开
  2. 上半部分是练习数据（已备好，请勿改动）
  3. 在下方黄色 「你的答案」 列输入公式，回车
  4. 「验证结果」 列自动判分：✓ 正确 / ✗ 再想想 / ○ 待作答
  5. 实在不会做：标准答案藏在 T 列（右键列标 → 取消隐藏）
